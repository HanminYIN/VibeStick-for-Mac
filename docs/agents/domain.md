# Domain docs

This repository uses a single domain context.

## Before exploring

- Read `CONTEXT.md` at the repository root when it exists.
- Read relevant decisions under `docs/adr/` when they exist.
- If either path is absent, continue silently; `/domain-modeling` creates domain material lazily when a real term or decision is resolved.

## Vocabulary

Use terms as defined in `CONTEXT.md`. When a necessary concept is missing, reconsider whether existing project language already covers it; otherwise record the gap for `/domain-modeling`.

## Decisions

Surface conflicts with an existing ADR explicitly instead of silently overriding it.
